# Acai-Select-From-Paradise
Repositorio criado para desenvolver o produto de software

## Contexto
O projeto Açaí Select From Paradise tem como objetivo desenvolver um banco de dados para organizar e gerenciar uma loja de açaí, facilitando o controle de clientes, pedidos, produtos, vendas e estoque.

O sistema permitirá registrar os pedidos realizados pelos clientes, armazenar os produtos disponíveis, controlar suas quantidades e acompanhar as vendas. Além disso, poderá sugerir promoções e descontos quando a demanda estiver baixa e possíveis ajustes de preços quando a procura estiver alta, com base no conceito de oferta e demanda.

O gerente será responsável por avaliar e decidir sobre as sugestões de preços e promoções, enquanto os atendentes utilizarão o sistema para cadastrar clientes e registrar pedidos. Os clientes poderão escolher os tamanhos, sabores e acompanhamentos de seus açaís, e o estoque será atualizado conforme a movimentação dos produtos.

Dessa forma, o banco de dados busca tornar a administração da loja mais organizada e eficiente, reduzir problemas de controle e contribuir para melhores decisões comerciais.
